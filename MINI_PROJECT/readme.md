### Мета роботи
закріпити роботу з процесами, файлами, сигналами, потоками, IPC, ресурсними обмеженнями, таймерами та засобами налагодження у Linux.
### Опис реалізації
Програму реалізовано мовою C з використанням POSIX. Працює в безкінечному циклі з керуванням веденння тексту. 
Для збереження фонових процесів використовується масив з структурами processes. 
Щоб уникнути зомбі, використовується обробка системних сигналів від дочірних класів про їх завершення. 
Використані системні виклики та функції:
* fork() — для створення нового процесу.
* kill() — для надсилання сигналу процесу за його PID для примусового завершення.
* sigaction() — для безпечного встановлення обробника сигналу SIGCHLD.
* waitpid() — для зчитування статусу завершених дочірніх процесів та видалення їх з таблиці процесів ОС.
* getpid() — для отримання ідентифікатора поточного запущеного процесу.
* exit() — для коректного завершення роботи дочірнього процесу після відпрацювання.
* sleep() — для зупинки виконання процесу на заданий час.
